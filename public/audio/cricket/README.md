# Cricket Pinball sound pack

Original procedural audio, generated by `scripts/build-cricket-audio.py` with a fixed seed. No third-party samples or runtime API calls. Mono 24 kHz PCM WAV for browser decoding.

Bat: resonant wooden impact. Flipper: short mechanical click. Rail: metallic impact. Launch: spring release. Wicket: three staggered wooden impacts. Crowd: layered synthesized applause and crowd texture, not a recording of a real audience.

The pack is an initial game sound-design pass. It must not be presented as recorded cricket audio. Playback is unlocked by player input; effects and crowd have separate persisted volume controls. Audio failures do not block the match.
