# Boot proportions and ball staging

Each boot now occupies 28% of board width (previously 37%) and 15% of board height (previously 20%). Pivots are inset to 18% and 82% of width and sit at 83% of height. The ball stages at 50% width, 76.5% height, ahead of the boots. Both human and CPU attempts use the same staging point. The existing forward-only shot trajectory cannot carry the ball behind this line.

Validation: 13 engine tests; real touch charge/release and actual boot swing; player and subsequent CPU shot tracking at 360×640, 390×844 and 844×390. Browser runs use the ordinary clock, without gameplay-state mutation. Screenshots are WebP. Build passes. Other game modes are untouched.
