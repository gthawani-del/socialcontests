# Crash — skill-based bank-or-lose
NO wagering, deposits, money or random hidden crash threshold. The football drains between two boot flippers = crash. BANK POINTS before drain secures virtual score and ends run; drain forfeits only unbanked round points. One ball; no extra lives in default mode. Pause freezes active simulation time.
Proposed survival multiplier M(t)=min(10,1+0.045*t+0.0015*t*t), t active simulation seconds. Version formula, cap, display rounding and integer arithmetic. Target base points proposed: small bumper +50; wing play +75; center +100; skill +150; goal zone +500. Repeated contact only scores once until target rearmed. The visual ×2/×3/×5 labels are **combo tiers**, not independently compounding score multipliers. Qualified hits add charge; combo C=min(1.5,1+0.1*charge), resets after 5s without a hit. BANKED=floor(BASE*M*C) using fixed-point arithmetic. Example 1000*2*1.2=2400.
Authoritative ordering: collision/drain events processed before bank action within the same simulation tick. Earlier bank succeeds; earlier drain loses. Reject duplicate banks, client-forged collisions, post-drain banks, manipulated clocks, score overflow and paused-time farming. Never secretly adjust gravity, flipper torque, ball speed or collision shape as multiplier increases.
Fairness: use canonical fixed-step authoritative physics (suggest 120Hz), versioned rules/collider hashes, ordered input commands by tick, event/score ledger, bank/drain tick, signed final result and reproducible canonical replay. Browser runtimes may not be bitwise deterministic: verify on canonical runtime before promising exact replay. Optional RNG: commit SHA256(seed||nonce||rulesVersion) before run, reveal after, verify draw sequence; this verifies RNG only, NOT skill outcomes. Do NOT advertise 'provably fair' until publicly verifiable replay/signature tooling and independent validation exist; call it auditable skill-based fairness.
UI: multiplier, base score, potential bank value, BANK POINTS, left/right touch flippers and visible drain. Replace reference 'CASH OUT ₹100'; never display money or fake crash history.
QA: bank-before-drain, drain-before-bank, same-tick ordering, pause, reproducible ledger, physics unaffected by multiplier, no double scoring.
